# multi_layer_CAB_analysis

Research conducted over Summer 2025 into Characteristic Activation Boundaries. This is a continuation of the work done by Dr Wenlin Chen, who first introduced Characteristic Activation Boundary Analysis for single-layer networks. Over Summer 2025, I extended this methodology to multi-layer networks. Over Summer 2026, I hope to correct the issues present in my previous work, apply this methodology to quantify the behaviour of neural networks during training, and publish my work.

Most of the programs are in the old_code section, as I am currently rewriting them in python to resolve certain library compatiilty problems.
